# Support

## Bugs

Use the GitHub bug report form and include reproducible steps, environment details, logs with secrets removed, and screenshots when helpful.

## Feature Ideas

Use the feature request form. Describe the user problem first, then the proposed solution and alternatives.

## Usage Questions

Search the documentation and existing issues first, then use [GitHub Discussions](https://github.com/yruichen/marketing-hub/discussions) for setup and usage questions.

## Security

Do not post vulnerabilities in Issues or Discussions. Follow [SECURITY.md](./SECURITY.md).

## Scope

Maintainer capacity is limited. Reproducible defects and focused proposals are prioritized over general consulting, custom deployment work, or provider-specific account support.
