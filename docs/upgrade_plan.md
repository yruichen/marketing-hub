# Marketing-Hub 新增功能与迭代计划 (V2)

## 1. 项目与活动管理 (Project & Campaign Management)
核心目标：建立全套的项目协作与归档体系，告别“单次生成、用完即走”的现状。
- **项目全生命周期管理**：支持新建、保存、编辑、删除营销项目（Project/Campaign）。
- **生成资产硬绑定**：所有的生成物（文案、图像、音视频）必须硬绑定至所属项目或活动下，方便分类与回溯。
- **进度与草稿同步**：即便工作流执行到一半，设定的输入和节点连线状态均能随项目自动保存，下次加载可直接恢复当前工作区。

## 2. 画布式无代码搭积木系统 (Lego-based Visual Agent Builder)
核心目标：实现“拖拽式画板”体验的智能体编排引擎。
- **动态节点连线白板 (Canvas & Nodes)**：引入无界画板式交互（类似 React Flow）。用户可以将独立的智能体卡片（如【小红书文案专家】、【配图生成器】）拖拽至画板。
- **积木式工作流编排**：通过连线决定生成的上下文流向和执行顺序。例如：将【品牌卖点提炼节点】的输出连入【文案生成节点】，再连入【发布节点】。
- **节点双击个性化配置**：支持对画板上的单个积木块进行高度自定义（如修改品牌语调、调整单节点的Prompt预设）。
- **实时执行与可视化反馈**：工作流支持一键运行，节点状态可视化（执行中、成功、报错），并在节点上实时渲染输出结果缩略图。

## 3. 全局特征感知与动态修正 (Context & Continuous Session)
- **全局品牌记忆设置**：在项目级别配置统一的品牌/受众特征，画板内的所有 Agent 节点默认共享该上下文，避免重复输入。
- **节点打回重做机制**：生成结果不满意时，可直接在对应节点发送“修改意见”，触发单节点局部重试或修正，无需打断或重开整个工作流。

## 4. 创作者社区体验升级 (Creator Community)
- **工作流模板一键 Fork**：用户可以分享整个“生成逻辑模板”（包含节点连线、积木组合），其他创作者可一键 Clone 并填入自己的需求。
- **瀑布流灵感板**：完全图像化的灵感墙展示社区产出，Hover卡片即可预览生成该内容的具体工作流图。

---

## 5. 阶段实施详细计划 (Milestones)

- **Phase 1: 项目管理底层与基础 UI**
  - 后端：设计并开发 Project/Campaign 核心数据表（CRUD 接口），完善资源绑定关系。
  - 前端：搭建“我的项目”列表页、详情页视图，实现工作区草稿保存与加载逻辑。

- **Phase 2: 拖拽式白板核心搭建**
  - 前端：引入可视化画布框架（如 React Flow），支持节点拖放、节点间的数据连线交互。
  - 节点：封装标准版节点组件（文案节点、图像节点），支持右侧面板高级参数配置。

- **Phase 3: 整体工作流链路打通**
  - 核心链路：画板引擎对接后端，支持按照节点连线顺序执行任务。
  - 体验完善：实现流式生成展示与局部节点重试功能，完成最终产出的预览与下载。
