# Marketing-Hub 产品功能详尽报告

## 1. 产品定位与核心认知
Marketing-Hub 是一款基于 Django（后端）与 React + Vite（前端）构建的全栈 AI 智能营销内容生成平台。全站 UI 采用了独有的 “Creative Draftbook（创意草稿本）” 拟物高对比度设计系统。产品坚决剥离了半透明玻璃拟态等花哨特效，整体应用单线实体墨水描边、零模糊的硬重力阴影（Hard Shadows）及无色彩渐变形制。在保障长文本与复杂信息流下的低视觉疲劳特性的同时，营造出“沉浸式桌面制图桌”的严谨与纯粹空间。

## 2. 设计语言与核心界面交互
### 2.1 纸张与黑板双模画布（Dual-Mode Canvas）
系统深度贯彻拟物白板机制，提供两种非高光低对比物理模式即时滑动切换：
- **Light Mode（温暖纸张）**：暖色调纸质背景（#FAF9F6），搭配高灰度纯黑墨水边界（#1A1A1A），再现传统记事本观感。
- **Dark Mode（粉笔黑板）**：以黑板深灰与白粉笔纯彩实线构成边界，保障夜间与昏暗下沉浸创作保护。

### 2.2 特色交互组件库
- **背景点阵网格（Dot Matrix Grid）**：画布背景植入类似手账的点阵基底（Light下为浅灰，Dark下为深石墨），赋予内容物理对齐感。
- **大头针便签框（Pinned Sticky Note）**：所有的核心 AI 提示词（Prompt）均置于带有双大头针固定的黄色高亮便签面板，输入态下伴随仿生立体卷边投影。
- **悬浮工具夹板（Floating Toolbelt）**：侧边目录区取消传统左右贴边与遮罩弹窗，转变为悬浮的矩形物理托板。通过索引文件夹（Folder Tabs）完成功能切换。
- **拍立得画廊卡（Polaroid Gallery Card）**：生成的图片与资源呈现皆封装于“拍立得式”宽底边白色相框中，底部带有复古等宽打字机字体（Monospace）元数据生成编码与微量随机倾角配置，模拟散落于桌面的实体相片。

## 3. 核心业务功能模块
### 3.1 📝 智能文案生成引擎 (Copy)
营销推广人员的核心基站，用于结构化文风改写与原创。
- **输入级设定**：提供【品牌名称】、【产品功能特性】、【发布目标平台（如 小红书、微信等）】与【推广调性（如“爆款活泼”）】。
- **输出级响应**：AI 提取输入意图并针对指定平台特性生成带有以下结构的模块化图文：
  - 符合平台推荐机制的诱导化与强吸睛标题。
  - 共鸣与情绪引导式的结构化正文分段。
  - 标准化 SEO 流量池标签（Tags）。
  - 执行指令导向收尾（Call to Action），直接赋能转化漏斗。

### 3.2 🎨 视觉图像生成引擎 (Image)
- **参数控制面板**：精准控制画幅比例（Aspect Ratio）、宏观艺术风格指令（Style）与前置画面自然语言（Prompt）。
- **智能改写双链路**：API 处理的产物不仅仅是最终渲染的高清多边形配图，同时会在面板展现 “Revised Prompt（重写提示词）”，即揭示大模型是如何将简短指令拓写为详细设定（包括光影调性、材质设定与渲染透视）的，提供极高的逆向参考价值。

### 3.3 🎬 分镜故事板策划系统 (Storyboard)
面向短视频创作者的剧本级策划分镜台。
- **入参维度**：用户只需给出【内容主轴】（Video Topic）、【拟定时长】（Duration）及【受众定位】（Audience）。
- **细粒度时间轴输出**：拆解后的时间轴节点对象呈现结构化场景剧本（Scene Timeline）：
  - **画面视觉维度**：摄像机景别调度规划、物理道具堆叠关系等动态场面描述。
  - **音频画白维度**：角色口播词与拟声、配乐描述的绑定。
  - **卡点时长**：每个分镜独立秒数计时，最终自动逼近视频总时长预期。

### 3.4 🔊 AI 语音合成 (Audio)
针对纯脚本及有声书场景提供的 Text-to-Speech 能力引擎。基于指定的文字，调整【拟真原声对象 ID】与【播报语速】，并实时返回估时及生成的音频流源部件（带定制化播放控件的胶片样式组件）。

## 5. 共创留存体系 (Feed / Community)
摒弃只停留于缓存的短视会话流机制，所有产生的 AI 材料（无论是一张图、一段口播，还是一套分镜）均可在操作盘直接**提交打包至全站手绘工坊社区（Community）**。
- 支持针对作品绑定独立 Title 进行打样发布。
- 以陈列墙排布，支持全局点赞（Likes）、元数据解析与重复度/雷同指代标位（Similarity Score）。

## 6. 配置中心与 Agent 运行追踪
### 6.1 Agent Terminal 探针日志流（代理监控终端）
系统有别于传统的等待沙漏或环形加载器。每次操作均暴露真实的交互处理日志流，并输出诸如 `[INFO] Initializing Editorial Sketch Image Agent Workflow...` 与多节点耗时状态码。通过硬核的信息公开机制增强后台黑盒的控制感。
### 6.2 大模型基核节点配置 (AI Config)
内建了动态切换 AI 引擎源的注册面卡片，管理员支持随时配置自定义 Proxy Domain、调用秘钥及默认启用的大语言视觉关联的模型（Model Name），保障服务的无缝接驳。
