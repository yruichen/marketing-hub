# 项目和资产库合二为一整改计划

## 1. 现状问题

目前项目和资产库是两个独立模块，数据关系如下：

```
Folder → Project → Asset
```

- **我的项目**：显示文件夹 → 项目列表，项目下显示资产数量
- **资产库**：显示所有资产，可按项目筛选

**问题：**
- 用户生成内容后需要先保存到资产库，再移动到项目，操作链太长
- 文件夹只能归类项目，不能直接归类资产
- 一类的活动资产分散在不同项目下，查看不方便

---

## 2. 目标设计

合二为一后，界面和数据关系变为：

```
Folder → (project + assets 混合展示)
```

### 界面结构

```
┌──────────────────────────────────────────────┐
│  左侧栏（文件夹）           │  主内容区          │
│                            │                  │
│  📂 全部资产               │  [当前文件夹内容]   │
│  📂 春季新品上市  ←选中     │                  │
│  📂 咖啡品牌               │  ┌─ 项目卡片 ──┐   │
│  📂 618大促                │  │ 项目名        │   │
│  📂 默认文件夹              │  │ 品牌记忆等     │   │
│                            │  └──────────────┘   │
│  [+ 新建文件夹]             │  ┌─ 资产卡片 ──┐   │
│                            │  │ 图片/文案等   │   │
│                            │  └──────────────┘   │
│                            │  ┌─ 资产卡片 ──┐   │
│                            │  │ 视频/音频等   │   │
│                            │  └──────────────┘   │
└──────────────────────────────────────────────┘
```

### 核心原则

- **文件夹是唯一的组织单元** — 代替"项目"作为内容容器
- **一个文件夹下可以同时有项目和资产**
- **生成时直接选择保存到文件夹**（替代保存到项目）
- **删除"我的项目"和"资产库"两个独立入口**，合并为一个统一入口
- 左侧导航栏只保留一个入口，例如叫**「工作区」**

---

## 3. 数据模型改动

### Asset 新增 folder 字段

```python
class Asset(models.Model):
    # ... 现有字段 ...
    folder = models.ForeignKey(Folder, on_delete=models.SET_NULL, 
                                null=True, blank=True, related_name='assets')
```

需要一次迁移。

### 含义

```
改动前：Asset → Project → Folder
        （资产通过项目间接关联文件夹）

改动后：Asset → Folder (直接)
        Asset → Project (保留，可选)
        Project → Folder (保留)
        
        文件夹下同时列出属于它的项目和资产
```

## 5. 界面交互流程

### 5.1 生成内容 → 保存到文件夹

```
用户在生成面板点击「保存到资产库」
  → 弹窗选择文件夹（默认：当前选中的文件夹）
  → 保存后资产直接关联到文件夹
  → 在「工作区」对应文件夹下可见
```

### 5.2 日常浏览

```
左侧栏点击文件夹
  → 右侧显示该文件夹的所有内容：
     ├── 项目卡片（项目名、品牌记忆、活动数）
     └── 资产卡片（图片/文案/视频预览、标签）
```

### 5.3 拖拽归类

```
资产卡片可直接拖拽到左侧其他文件夹
  → 更新 asset.folder_id
```

## 6. MVP 方案（先做最小的）

考虑到改动量，建议 MVP 只做最核心的：

1. **Asset 加 `folder` 字段** + 迁移
2. **删除独立资产库入口**，合并到"我的项目"页面
3. **文件夹下直接显示资产卡片**（现有看板视图增强）
4. **保存控制栏增加文件夹选择**

这样用户就能在文件夹级别直接管理资产，不再需要"保存到资产库 → 移动到项目"两步操作。

| 项目 | 评估 |
|:----|:-----|
| 改动范围 | 中等（~8个文件） |

| 回退方案 | 保留"资产库"独立页面作为备选入口 |
