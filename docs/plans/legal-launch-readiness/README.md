# 上线前法律责任与合规准备计划

版本：V1  
日期：2026-06-27  
范围：Marketing Hub SaaS、AI 内容生成、工作流编排、资产库、社区/模板、BYOK、管理后台、计费展示

> 说明：本文档是产品、工程、运营和法务协作清单，不构成法律意见。上线前必须由具备目标市场资质的律师或合规顾问复核。

## 1. 目标

上线前必须把法律责任从“事后补救”变成产品和工程默认能力：

- 用户知道平台如何收集、使用、保存、共享数据。
- 用户知道 AI 生成内容的责任边界、使用限制和审核义务。
- 平台能识别、标记、追踪和处理 AI 生成内容。
- 平台能处理侵权投诉、违法违规内容、广告合规风险和数据主体请求。
- 平台能证明关键行为、授权、同意、模型调用和内容发布路径。

## 2. 适用法规与参考方向

中国大陆上线或面向中国用户时，重点关注：

- 《个人信息保护法》：个人信息处理、告知同意、敏感个人信息、个人权利、跨境提供。
- 《网络安全法》《数据安全法》：网络运营者安全保护、数据分类分级、安全事件处置。
- 《生成式人工智能服务管理暂行办法》：面向公众提供生成式 AI 服务时的内容安全、数据来源、标识、投诉处理等要求。
- 《互联网信息服务深度合成管理规定》：深度合成内容标识、技术支持者/服务提供者责任。
- 《人工智能生成合成内容标识办法》及配套标准：AI 生成合成内容的显式/隐式标识要求。
- 《互联网广告管理办法》《广告法》：广告内容真实性、绝对化用语、代言/推荐、特殊行业广告。
- 《著作权法》《商标法》《反不正当竞争法》：素材、品牌、模板、社区内容和模型输出的权利风险。
- 《消费者权益保护法》《电子商务法》：若平台承载交易、付费订阅、退款、发票或服务承诺。

若面向海外用户，还需要按目标市场补充：

- EU：GDPR、EU AI Act、Digital Services Act。
- US：FTC advertising/AI claims guidance、state privacy laws、DMCA、COPPA。
- 其他地区：本地隐私、广告、消费者保护、AI 生成内容标识规则。

## 4. 责任边界原则

Marketing Hub 应明确区分四类责任：

- 平台责任：账户、数据安全、AI 服务配置、日志、标识、投诉处理、违法内容处置。
- 用户责任：输入素材合法性、品牌/商标授权、发布前审核、广告真实性、使用输出内容的最终责任。
- 模型/第三方责任：外部 provider 的服务条款、数据处理、可用性和模型限制。
- 共同责任：BYOK、团队协作、社区模板、工作流共享、生成内容对外发布。

## 5. 上线法律风险等级

| 风险 | 等级 | 上线前要求 |
| --- | --- | --- |
| 未发布隐私政策/服务条款 | P0 | 禁止上线 |
| 未记录用户同意和条款版本 | P0 | 禁止开放注册 |
| AI 生成内容无标识和追踪 | P0 | 禁止开放社区/外部发布 |
| 用户上传素材无授权声明 | P0 | 禁止开放素材库/模板共享 |
| 无投诉/举报/侵权处理入口 | P0 | 禁止开放社区 |
| 敏感个人信息或跨境数据未评估 | P0 | 禁止生产使用 |
| 广告合规无审核机制 | P1 | 限制高风险行业和公开发布 |
| BYOK 条款和密钥安全未明确 | P1 | 禁止企业 BYOK |
| 计费、退款、发票说明不清 | P1 | 禁止收费上线 |

## 6. 推荐上线策略

1. 封闭测试阶段只开放受邀用户，不开放公开社区索引和公开模板市场。
2. 所有 AI 输出默认标记为“AI 生成初稿，发布前需人工审核”。
3. 高风险行业默认关闭或进入人工审核：医疗、药品、金融、投资、教育升学、未成年人、保健品、法律服务。
4. 社区发布、模板共享、公开主页必须先完成举报/下架/侵权处理机制。
5. 收费功能上线前必须完成订阅条款、退款规则、发票/税务说明和额度消耗解释。
