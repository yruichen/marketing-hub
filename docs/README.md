## Documentation Rules

- Keep operational docs short and actionable.
- Put long-term architecture decisions in `architecture/`.
- Put active implementation plans in `plans/`.
- Move old reports, pitch drafts, and superseded strategy docs to `archive/`.
- Update this index whenever adding or moving a document.
- Prefer current behavior over aspirational claims.
