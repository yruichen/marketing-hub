# Community Code of Conduct

Marketing Hub is built through thoughtful, respectful collaboration.

## Expected Behavior

- Be constructive, specific, and kind.
- Critique ideas and code rather than people.
- Welcome contributors with different backgrounds and experience levels.
- Respect privacy, attribution, and intellectual property.
- Keep technical discussions focused on improving the project.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate disruption, and repeated bad-faith behavior are not tolerated.

## Reporting

Report conduct concerns privately to the repository maintainers through GitHub. Do not use public issues to disclose sensitive personal information.

Maintainers may edit or remove content, close or lock conversations, reject contributions, or restrict participation when needed to protect the community.

## Scope

This policy applies in repository discussions, issues, pull requests, reviews, and other spaces where someone represents the Marketing Hub project.
